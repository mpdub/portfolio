# Martin Wong — portfolio

🐷 oink. Just keeping the place warm.

A static advertising portfolio with 16 campaigns, built with HTML, CSS and JavaScript.

## Editing

- `data.js`: campaign copy, order, image references and video links.
- `index.html`: homepage intro, About, experience and contact details.
- `project.js`: shared case-page layout, films, galleries and animations.
- `site.js`: homepage campaign grid and pig interaction.
- `styles.css`: typography, spacing and responsive layouts.
- `assets/`: optimised images and short looping clips. Films are hosted on YouTube or Vimeo.

The website files are at the repository root; no build step or package installation is required. A `.nojekyll` file prepares them for GitHub Pages.

## Publishing status

GitHub Pages is deliberately disabled. The custom domain `martinw.ong` (Porkbun) has not been connected. Enable publishing and change DNS only when Martin explicitly requests launch.

The existing review site is https://martin-wong-portfolio.whitefox228713.chatgpt.site . It is a separate deployment; changing this repository does not automatically update that preview.

## Future updates

This repository contains the complete website and can be edited through the connected GitHub account. Preserve the latest repository changes when preparing future updates. Once GitHub Pages is enabled, pushes to its configured publishing branch will update the live site.
